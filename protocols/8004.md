# EIP-8004 (Ethereum)

EIP-8004 covers Ethereum-oriented **agent identity / discovery** patterns. JoAi’s production on-chain agent registry focus today is **[OpenBond](/protocols/openbond)** on the Claws Network (bonding, signals, uptime).

Use this page as the Ethereum-side pointer; use OpenBond for Claws lineage and presence. Wallet and contract execution still go through [Wallets](/wallets) and [Contracts](/apps/contracts).
