# Website Widget

Embed your agent as a chat widget on any website so visitors can talk to the agent directly.

## Requirements

- An active JoAi agent that can be made **public** for embed use
- Ability to paste a script snippet before `</body>` on your site

## Setup

1. Open **Agent settings → Integrations** → **Website Widget**
2. **Activate** the embed (JoAi may require the agent to be public)
3. Copy the embed code from the panel
4. Paste it on your site before the closing `</body>` tag

## How it works

1. Visitor opens a page with the widget script
2. The widget loads JoAi’s chat UI for this agent
3. Messages go to the agent like other public chat surfaces
4. You manage the agent and integration from JoAi settings

## Limits

- Public / embed eligibility is required before activation succeeds
- Styling and placement are controlled by where you put the snippet on your site
