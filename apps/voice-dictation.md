# Voice dictation

Voice dictation is the desktop **system voice control** native app: speak to JoAi with push-to-talk or hands-free mode. Install it under **Team settings → Apps** on the **desktop** app only (hidden from web/mobile installers).

## Overview

- System-wide voice control overlay on desktop
- **Push-to-talk** (`fn`) and **hands-free** (`fn` `fn`)
- Optional **voice responses** (agent speaks aloud) + voice picker
- Playback routing: both / voice-control only / chat only
- Spelling **corrections** and recent transcriptions (stored on-device)
- Distinct from agent **live voice / phone** features (plan-gated on the agent)

## In the app

### Install

1. On desktop, open **Team settings → Apps**
2. Install **Voice dictation**
3. Open **Settings → Voice** (`VoiceControlSettings`)

### Settings → Voice

| Control | Meaning |
| --- | --- |
| **Enabled** | Turn system voice control on/off |
| **Voice responses** | Active agent speaks replies aloud |
| **Voice** | Pick a TTS voice when responses are on |
| **Speak in** | `both` · `voice-control` only · `chat` only |
| **Push-to-talk** | Hold **fn** to transcribe |
| **Hands-free** | Double-tap **fn** **fn** for continuous mode |
| **Corrections** | Custom spelling / phrase fixes |
| **Recent transcriptions** | On-device history (not uploaded as a cloud log) |

### Not the same as

- **Agent voice-live / phone** — conversational voice on the agent (separate agent settings, plan-gated)
- **Meetings** transcription — [Meetings](/apps/meeting) records meeting audio, not desktop dictation

## For agents

No Voice-dictation MCP tools — this is a human input feature for the desktop client.
