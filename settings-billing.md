# Settings & Billing

## User Settings

Access via **Settings** in main navigation:

- **General** - Language, theme preferences
- **Profile** - User information
- **Wallets** - Personal wallet management
- **Notifications** - Notification preferences

## Team Billing

Access via **Team Settings > Billing**:

- **Current Plan** - View active subscription
- **Plans** - Browse available plans
- **Upgrade/Downgrade** - Change subscription level
- **Payment Methods** - Manage payment information
- **Billing History** - View invoices and payments
- **Cancel Subscription** - End subscription (lose access at cycle end)

## Subscription Features

Plans provide:

- **Premium Features** - Advanced capabilities
- **Higher Limits** - Increased usage (messages, agents)
- **Priority Support** - Faster support response
- **Additional Resources** - More agents, wallets, etc.

## Usage Monitoring

Monitor team usage:

- **Messages** - Track consumption vs. limits
- **Feature Usage** - See which features are used
- **Usage History** - Historical data
- **Alerts** - Notifications when approaching limits
