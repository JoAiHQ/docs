# Best Practices

## General

- Start with blueprints to learn
- Test configurations before relying on them
- Monitor agent activity regularly
- Keep backups of important data
- Document your setups

## Security

- Always backup mnemonic phrases securely
- Never share recovery phrases or private keys
- Use strong passwords
- Enable two-factor authentication where available
- Regularly review access and permissions

## Performance

- Monitor usage to optimize costs
- Use auto mode for faster workflows
- Set up alerts for important events
- Regular maintenance and updates
- Optimize agent configurations

## Collaboration

- Use clear naming conventions
- Document team processes
- Regular team reviews
- Appropriate role assignments
- Monitor team usage
