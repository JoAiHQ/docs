# Billing & plans

Billing covers team subscriptions, usage limits, Extra Usage, invoices, and MCP credits. Open **Settings → Usage & Billing** (`/teams/settings/usage`). Public plan comparison also lives on **Plans** (`/plans`).

## Overview

- Team **subscription** unlocks higher limits and premium features
- **Usage** shows consumption vs plan allowances (messages, alerts, links, wallets, …)
- **Extra Usage** top-ups when you hit caps
- **MCP credits** are part of the plan — see [MCP](/protocols/mcp#credits-usage)
- Feature gates appear as upgrade nudges across Shop, Studio, Alerts, Smart Links, etc.

## In the app

### Usage & Billing

1. Open **Settings → Usage & Billing**
2. Review plan status and feature usage meters
3. Manage payment method / invoices where shown
4. Upgrade, change plan, or purchase Extra Usage as needed

### Plans page

Browse tiers and compare limits on the public **Plans** surface, then subscribe for the active team.

### What plans typically gate

Examples (exact limits depend on plan):

- Alerts volume
- Smart Links quota
- Multi-wallet
- Custom domains (Sites)
- Premium cloud wallet providers
- Cards / widgets
- Higher MCP credit allowances

Locked features show an upgrade nudge instead of the action.

## MCP credits

Tool calls consume monthly **credits**. Credits reset each billing cycle. Details and overage: [MCP credits](/protocols/mcp#credits-usage).

## Tips

- Check Usage before a big campaign or Studio batch
- Prefer Extra Usage for short spikes; upgrade for sustained load
- Agent wallets and personal Settings → Wallets are separate from billing payment methods
