# Getting Started

AI agents that actually do things. With all the core AI capabilities you expect, plus the ability to interact with Web3 blockchains and apps you use every day - all in one place.

## What is JoAi?

JoAi is next-generation AI agents. Instead of switching between multiple apps, JoAi gives you a single assistant that can:

- **Ask questions** - Get answers with web search and knowledge base
- **Analyze documents** - Upload PDFs and get summaries, answers, and insights
- **Understand images** - Analyze and describe images
- **Voice conversations** - Talk naturally with voice mode
- **Set reminders** - Create reminders with push notifications
- **Automate workflows** - Build custom skills with warps - no coding needed
- **Blockchain Support** - Interact with Sui, Solana, Ethereum, Base, MultiversX, and EVM chains
- **Manage digital assets** - Built-in Web3 digital wallets for blockchain networks
- **Connect services** - Integrate with Slack, Telegram, Apple Health, and more

Most users don't want five different AI apps - they want one place that does it all. JoAi bundles everything into a single assistant that becomes part of your daily workflow, powered by next-generation technology.

## Key Concepts

- **Agents** - Next-gen AI assistants with natural language understanding and powerful skills
- **Skills** - Unlimited capabilities agents can use. Create custom skills with warps - no coding needed
- **Blockchain Support** - Web3 digital wallets for Sui, Solana, Ethereum, Base, MultiversX, and EVM chains
- **Knowledge Base** - Upload documents for agents to reference and learn from
- **Reminders & Tasks** - Set reminders with push notifications and automated recurring tasks
- **Swarms** - Groups of agents working together on complex tasks
- **Teams** - Collaborative workspaces for multiple users
- **Wallets** - Web3 digital wallets for managing digital assets across blockchain networks
- **Blueprints** - Pre-configured agent templates to get started quickly

## Onboarding

When you first sign in, you'll complete a brief onboarding:

1. **Welcome** - Introduction to JoAi
2. **Authentication** - Complete account setup (email, social login, or wallet)
3. **First Agent** - Create or select your first agent

After onboarding, you'll be taken to your home dashboard where you can start interacting with agents.
