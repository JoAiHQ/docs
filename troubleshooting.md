# Troubleshooting

## Agents Not Responding

- Check agent is online
- Verify connection
- Refresh page
- Check agent settings
- Review agent mode (Local/Cloud/External)

## Actions Not Executing

- Verify action is properly configured
- Check required inputs provided
- Ensure wallets funded (if needed)
- Review error messages
- Check agent permissions
- Verify in manual vs. auto mode

## Wallets Not Working

- Verify wallet is active
- Check network connection
- Ensure sufficient balance
- Review wallet settings
- Try manual sync

## Integrations Not Working

- Verify credentials correct
- Check service status
- Review integration logs
- Test connection manually
- Ensure permissions correct
- Try reconnecting

## Swarm Coordination Issues

- Verify agents properly added
- Check agent permissions
- Ensure agents have required wallets
- Review swarm settings
- Check proposal approval status

## Team Access Issues

- Verify you're a team member
- Check your role and permissions
- Ensure correct team selected
- Contact team owner/admin
